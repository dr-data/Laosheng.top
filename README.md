　　這裏是民間網站[老生常談](https://Laosheng.top)，以‘集成網頁’爲特色的**研究型導航網站**。本站**收錄**四大系列的官方**網址**：法律、新聞、政務（經濟/民生）、全球化。這些官網有的是信息披露的法定媒體，有的是網絡新聞的稿源單位。快速找到這些官網，有益於網民分辨信息真僞、節省學習時間、投入國家建設。

　　在網址收錄過程中，大萌發現問題、研究問題、解決問題，爲這些網址**設計**高質量的結構性目錄，創作容易檢索的[大規模集成網頁](https://cn.bing.com/search?q=大規模集成網頁){:target="_blank"}(LSIP)<sup>⇗</sup>。希望能幫助<u>瀏覽器用戶</u>快速找到有效信息，引領<u>網絡學習者</u>打開新世界的門徑，對服務網址查缺查重，見證中華民族偉大復興。老生常談網站摘要如下，詳細內容請進入各系列頁面。
